# 中国庇护案常见类型：要件框架与薄弱点

整理案卷到第 4 步（法律要件对照）时，先判断口述属于下面哪一类或哪几类，读对应的一节。一个案子常常跨类：强拆户去上访被拘留，既是强拆也是上访；教会信徒在网上发帖被约谈，既是宗教也是言论。跨类的每类都读，要件对照时分别写。

每节四项：**nexus 落在哪**（法官认的受保护理由是什么，不是客户以为的）、**典型事件链**（口述里该有哪些环节）、**应有证据**、**法官常追的薄弱点与追问**。

判例只列最常碰到的几个，判例状态会变（尤其家暴类），标出来是提醒律师去核对现行判例，不是让整理时下结论。

## 1. 家庭教会 / 基督教

**nexus**：宗教。要落实的是客户因为信仰或参加未登记的聚会被政府针对，而不只是"聚会被冲了"。

**典型事件链**：怎么信的（谁带的、哪年）→ 在哪聚会、多久一次、多少人 → 第一次被冲 / 被带走 → 拘留、审问、签保证书、罚款 → 之后有没有继续 → 再次被抓或被监视 → 工作单位 / 学校 / 村委有没有施压 → 离境。

**应有证据**：受洗证明或教友证词（国内的和美国的）；聚会照片；拘留通知书、释放证明、罚款收据；保证书副本；美国教会的参加证明和牧师信；圣经知识（面谈会考）。

**薄弱点与追问**：
- 为什么不去三自教会？客户得讲得出自己的理由，不是律师教的。
- 被抓后"不敢去了"又去了：隔多久、为什么、换没换地点、怎么知道安全。
- 信仰基本知识：受洗日期、谁施洗、常读哪卷、聚会流程。答不上来法官会认为信仰不真。
- 来美后有没有继续：哪个教会、多久一次、受洗没有、能否出证明。
- 家人还在国内有没有继续聚会、有没有被找——如果家人照常聚会没事，为什么客户回去会有事。
- 拘留天数、审问几次、谁审：数字类零容忍。

## 2. 地下天主教会

和第 1 节框架相同，另加：
- 客户要分得清地下教会和爱国会，讲得出自己为什么选地下教会。
- 神父身份：是否被官方认可、现在在哪、能否出证明。
- 梵中协议后部分地区形势有变，客户所在教区的实际情况要问清，不能泛泛说"天主教被打压"。

## 3. 法轮功

**nexus**：宗教和政治观点双线走。政府把法轮功定为"邪教"并作为政治问题处理，两条都要在口述里有支撑。

**典型事件链**：何时开始、谁介绍 → 炼功地点、频率、同修 → 1999 年取缔后怎么继续 → 被举报 / 被抓 → 拘留、转化班、洗脑班、劳教或判刑 → 单位处理 → 离境。

**应有证据**：同修证词；劳教或拘留文书（这类客户有时真有）；医疗记录（如被殴打）；来美后参加炼功点、讲真相活动的照片与证明；法轮功团体的证明信。

**薄弱点与追问**：
- 对功法的了解：五套功法叫什么、《转法轮》讲什么、三个字的原则。面谈必考。
- 开始炼功的时间和 1999 年的关系：取缔前还是取缔后开始的，取缔后开始的要讲为什么。
- 来美后有没有继续炼、参加活动：没有继续的，为什么。
- 拘留期间的具体：关在哪、多久、有没有转化班、签没签"三书"。
- 很多法轮功案件被法官见过太多模板化陈述，口述里的个人化细节（为什么是我、我所在的炼功点具体怎样）比模板更重要。整理时把个人化细节单独标出来。

## 4. 新疆穆斯林、藏传佛教

**nexus**：民族 + 宗教，叠加后针对性强，法官一般不要求证明个人被单独盯上到同等程度（pattern-and-practice 论证），但个人经历仍然要有。

**典型事件链**：身份证地址、民族成分 → 日常宗教活动受限的具体经历 → 被登记、被约谈、被送学习班 / 集中教育 → 家人被拘 → 护照被收缴后怎么拿回来、怎么出的境。

**应有证据**：身份证明（民族成分）；家人被拘的任何文书或证词；护照记录；国情报告（这类案子国情材料分量大，律师准备）。

**薄弱点与追问**：
- 怎么拿到护照、怎么出境的：这类客户出境本身就不寻常，要讲清楚，讲不清楚是大漏洞。
- 家人现状、还能不能联系、上次联系是什么时候。
- 个人经历和"大家都这样"的区分：哪些是自己经历的，哪些是听说的。

## 5. 计划生育

**nexus**：法定。INA §101(a)(42) 规定被强制堕胎或绝育、或因抵抗强制计生被迫害的，视为基于政治观点的迫害。

**关键区分**（法官一定问）：
- **本人**被强制堕胎 / 绝育：直接构成过去迫害。
- **配偶**被强制：本人不自动构成（Matter of J-S-，2008）。本人要么有自己的"其他抵抗"（other resistance）并因此被迫害，要么有自己的充分恐惧。口述里要找本人做了什么、被怎么对待。
- 上环（IUD）：一般不单独构成迫害（Matter of M-F-W- & L-G-），除非有加重情节（暴力强制、健康损害）。
- 罚款、开除、拆房：单靠经济处罚难构成，要看严重程度和有没有后续。

**典型事件链**：结婚、生育情况 → 怀孕被发现（谁举报） → 被带去医院的过程（谁带、强制到什么程度、有没有签字） → 手术（哪家医院、哪天、后果） → 之后的处罚 → 现在年龄、还会不会被针对。

**应有证据**：结婚证、孩子出生证明；医院记录（堕胎证明、绝育证明——国内有时能开）；罚款收据、处罚决定书；证人（家人、邻居）。

**薄弱点与追问**：
- 手术日期、医院、谁签的字、签的什么：数字和文件零容忍。
- "强制"的程度：是被拖去的，还是被说服去的、自己走去的。法官在这里分界。
- 二孩、三孩政策后的回国风险：客户现在的年龄、生育状况下，回去还会被针对的理由是什么。政策变了之后这一点是最常被打的。
- 配偶案件：本人到底做了什么抵抗，口述里经常是空的。

## 6. 强拆 / 征地

**nexus**：强拆本身是财产纠纷，法官不认为是迫害。能成立的路径是：客户反抗、上访、公开发声 → 政府把他当政治麻烦处理 → 构成（推定）政治观点。整理时把"拆迁经过"和"反抗之后被怎么对待"分开，后者才是案子。

**典型事件链**：房产情况（产权、面积、几口人住） → 拆迁通知、补偿方案 → 为什么不接受 → 做了什么（拒签、堵门、上访、发帖、组织邻居） → 政府反应（强拆过程、拘留、殴打、截访、威胁家人） → 之后的监控 → 离境。

**应有证据**：房产证、拆迁通知、补偿协议或拒签记录；强拆现场照片 / 视频；上访登记、信访回执；拘留通知书；医疗记录；邻居证词。

**薄弱点与追问**：
- 补偿到底是多少、别人接受了没有、客户为什么不接受：法官会想这是不是讨价还价。
- 上访几次、去了哪一级（县、市、省、北京）、每次结果：要具体。
- 被拘留是因为上访还是因为阻挠拆迁现场（后者更容易被定性为治安处理）。
- 房子拆了之后客户住哪、还继续上访吗、政府还在找他吗——如果拆完就没事了，回去的风险在哪。
- 同一个拆迁项目里其他反抗的人现在怎么样。

## 7. 上访户

适用：退伍军人待遇、下岗 / 买断、医疗事故、劳资纠纷、司法不公、村干部腐败等起因的上访。起因各异，案子的框架一样。

**nexus**：（推定）政治观点。起因是纠纷不要紧，要落实的是上访行为被政府当成政治问题处理：截访、黑监狱、拘留、"寻衅滋事"、训诫书、被单位开除、家人被施压。

**典型事件链**：起因 → 地方解决不了 → 第一次上访（哪里、怎么去的、递了什么） → 被截访 / 被带回 → 处理（关、打、签保证书、训诫） → 继续上访 → 处理升级（行政拘留、刑拘、判刑） → 被列入"重点人员"、敏感日期被看管 → 离境。

**应有证据**：信访回执、登记单；训诫书、拘留通知书、释放证明；判决书（如有）；截访时的照片、录音；同案访民证词；单位处理文件。

**薄弱点与追问**：
- 上访次数、每次日期、地点、递交对象：这是整个案子的骨架，数字类零容忍。
- 每次被截访后的具体处理：关在哪（宾馆、黑监狱、派出所）、几天、谁看管。
- 为什么过了这么久才走、怎么办的护照（重点人员通常被限制出境，拿到护照要解释）。
- 离开后家人有没有被找、上访的事有没有人接着管。
- 起因和政治的关系：法官会问"你是对政府不满，还是只想要赔偿"——客户得讲得出自己的理解。

## 8. 网上言论

**nexus**：政治观点。要落实的是客户发了什么、谁看到、政府怎么反应。

**典型事件链**：平台、账号 → 发了什么内容（具体到哪几条）、什么时候 → 被封号 / 被约谈 / 被拘留（谁来的、怎么找到的） → 训诫、保证书、删帖 → 之后有没有继续发 → 离境。

**应有证据**：帖子截图（带日期、账号）；封号通知；约谈记录、训诫书；拘留文书；账号现状（能否登录）。

**薄弱点与追问**：
- 帖子原文还有没有：删了的，有没有截图，谁截的，什么时候截的。
- 发的内容具体是什么：客户要能复述大意。
- 多少粉丝、多少转发：影响法官对"政府为什么盯上他"的判断。
- 约谈几次、谁约的（网警、国保、单位）、说了什么。
- 来美后还发不发：发的话内容、平台、有没有被国内的人看到；不发的话为什么。

## 9. 民主运动 / 异见活动 / 白纸运动 / 香港

**nexus**：政治观点，直接。

**典型事件链**：怎么开始参与、参与了什么（具体活动、日期、地点、规模） → 组织关系（有没有加入组织、什么角色） → 被抓、被审、被判 → 后续监控、单位处理 → 离境。

白纸运动（2022 年 11 月）、香港（2019–2020 反送中，2020 年国安法后）这两类事件时间集中，客户讲的日期、地点要和他自己的其他陈述对得上；整理时不要拿公共事件的日期去对客户，只比客户自己前后说的。

**应有证据**：活动照片、视频；组织成员证明；传唤、拘留、起诉文书；判决书；新闻报道（如有提到客户）；同伴证词；来美后继续参与的证明。

**薄弱点与追问**：
- 具体参与程度：到场看了，还是组织、发言、拉横幅。法官要分"路人"和"参与者"。
- 被抓的具体：谁、哪里、关了多久、问了什么、签了什么。
- 组织身份：加入了什么组织、什么时候、谁介绍、职务、交没交会费（海外民运组织的会员身份法官会问细节）。
- 来美后有没有继续：没有的话为什么。

## 10. 维权律师、劳工活动、独立记者

框架同第 9 节，另加：
- 职业身份的证明：执业证、记者证、吊销文件、劳工组织材料。
- 代理过 / 报道过 / 组织过的具体事件：案名、时间、结果。
- 职业身份被剥夺的过程本身就是迫害的一部分，单独列事件。

## 11. 家属连带（推定政治观点）

**nexus**：推定政治观点（imputed political opinion）。客户本人可能什么都没做，政府因为他的父亲、配偶、子女的身份而针对他。

**要落实的**：
- 那位家属具体是谁、做了什么、现在什么状态（在押、在逃、在海外）。
- 政府针对客户本人做了什么：约谈、监视、限制出境、单位施压、子女上学受影响。这一条口述里经常空——客户只讲家属的事，不讲自己的。
- 政府是否明确把客户和家属的政治观点联系起来（说过什么、问过什么）。

**薄弱点与追问**：
- 客户本人到底被怎样了：没有具体的，案子只剩"恐惧"，要件不够。
- 其他家属怎么样：同样是家属的兄弟姐妹如果没事，为什么客户有事。

## 12. 同性恋 / 跨性别

**nexus**：特定社会团体（PSG）。性取向作为 PSG 自 Matter of Toboso-Alfonso（1990）起稳定。中国案件的难点通常不在 PSG 成立与否，而在过去迫害的严重程度和回国风险的个人化。

**典型事件链**：何时意识到、何时出柜（对谁） → 家庭反应（强制治疗、逼婚、暴力） → 社会 / 单位 / 警方反应（骚扰、拘留、"扭转治疗"） → 在国内的伴侣、社群 → 离境 → 在美国的生活。

**应有证据**：在美国的生活证据分量最大——伴侣证词、社群组织参与证明、照片、社交媒体；国内的医疗记录（扭转治疗）、报警记录；朋友证词。

**薄弱点与追问**：
- 过去迫害是不是主要来自家庭：家庭暴力要落到"政府不能或不愿保护"，问有没有报警、警方怎么处理。
- 回国风险的个人化：中国没有把同性恋入罪，法官会问具体回去会发生什么、谁会做。
- 在美国的生活是否与所述身份一致：这是法官判断真实性的主要依据，整理时把这部分证据单独列全。
- 有没有异性婚姻、孩子：有的话要讲清楚。

## 13. 家暴

**nexus**：PSG。这一类的判例反复变动（Matter of A-R-C-G-，2014；Matter of A-B-，2018 推翻，2021 被撤销；之后仍有变化），PSG 的界定方式决定成败，**律师必须核对整理当时的现行判例**。整理时把事实按两条线分开列：施暴本身的严重程度，以及政府不能或不愿保护的证据。

**典型事件链**：关系、施暴者身份 → 施暴经过（频率、严重程度、受伤） → 报警（几次、警方做了什么、有没有记录） → 求助（妇联、居委、法院、保护令） → 离开的尝试、施暴者追踪 → 离境。

**应有证据**：医疗记录；报警回执或不受理记录；保护令申请；妇联、居委的记录；证人；照片。

**薄弱点与追问**：
- 报警是整个案子的关键：报了几次、每次警方怎么做的、有没有书面的东西。没报过警的，为什么。
- 施暴者现在在哪、还在找吗。
- 为什么不能搬到别的城市：施暴者有没有能力在全国找到她。
- 性暴力只记是否发生、时间、报案就医，不展开。

## 14. 艾滋病感染者

**nexus**：PSG。要落实的是因感染者身份受到的具体对待（拒诊、开除、信息泄露、警方骚扰），以及回国后的医疗和社会处境。

**应有证据**：确诊记录；拒诊、开除的书面证据；在美国的治疗记录。

**薄弱点与追问**：
- 国内有没有接受过治疗、为什么中断。
- 具体的歧视事件：谁、什么时候、做了什么。单靠"社会歧视"不够。

## 15. 来美后才开始的活动（sur place）

跨类：来美后才信教、才炼功、才加入民运组织、才在网上发帖的，都归这一节处理，和主类型的那一节一起读。

**法律上**：来美后的活动可以成为庇护理由，但法官会着重审查真实性（是不是为了庇护才做的）和中国政府是否知道。

**要落实的**：
- 开始的时间和递交庇护申请的时间关系。
- 活动的具体和持续：频率、角色、持续了多久。
- 中国政府是否知道：怎么知道的（家人被找、账号被封、公开露脸的照片在哪发的）。
- 国内有没有任何前史：来美前完全没有接触过的，要讲清楚来美后为什么开始。

**薄弱点与追问**：
- "为什么来美后才开始"是法官必问的，客户要有自己的回答。
- 国内家人有没有因此被找：没有的话，政府知道的证据是什么。
- 活动是否持续到现在：申请递交后就停了的，法官会认为是为申请做的。
