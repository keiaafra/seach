# 庇护客户口述整理

律师和客户谈完一场，手里是几千字乱序的口述：客户想到哪讲到哪，日期是"大概那年冬天"，同一件事讲了三遍每遍略有不同，中间夹着对律师的提问和对家人的抱怨。这个 skill 的工作是把这堆材料变成律师能直接用的案卷——不是把故事重讲一遍，而是把它拆成可核对的事实，摆到法律要件和证据上去看，找出哪里站不住、哪里还没问。

整理的成果会直接影响 I-589、书面陈述（declaration）和庭审准备。所以整理时的底线只有一条：**案卷里的每一个事实都要能回指到客户的原话。** 客户没说的，写"未提及"；客户说得含糊的，照含糊写，不替他补精确；两次说法不一样的，两句都留着并排放。律师要的是真实的全貌，包括不好看的部分——替客户圆上的漏洞会在庭审上以更糟的方式冒出来。

## 输入

可能拿到的是：

- 律师的面谈笔记（可能是电报体、中英夹杂）
- 录音转写稿（口语、重复、有转写错误）
- 客户自己写的或微信发来的长段文字
- 以上几种拼在一起，有时还附带已有的 I-589 草稿或旧陈述

先通读全部材料再动笔。口述常常是倒着讲的，开头说的"后来"要到结尾才知道指哪件事；通读一遍才能判断哪些片段在说同一件事。通读时记下：说话人是谁（客户本人、配偶代述、律师转述）、面谈日期、客户用的语言。这些决定后面怎么标注来源。

如果材料里混有律师自己的分析或问题，分开处理：客户说的才是事实来源，律师的推测标为律师推测。

## 整理流程

### 1. 拆事实

把口述拆成一件一件的具体事件。每件事记这些硬点：

| 硬点 | 要记什么 |
|---|---|
| 日期 | 客户怎么说就怎么记："2019年3月""那年春节前后""大概我儿子出生后半年"。相对日期不要换算成绝对日期——"儿子出生后半年"记为相对日期，并标明锚点是儿子出生 |
| 时长 / 次数 | 关了几天、打了几次、去了几回。客户报了数就记数；说"好几次"就记"好几次（未报具体数字）" |
| 地点 | 具体到客户说的粒度 |
| 在场的人 | 谁做的、谁看见了、几个人 |
| 客户怎么知道的 | 亲眼看见 / 亲身经历 / 家人告诉他的 / 自己推测的。这一条对可信度评估最关键，口述里经常混在一起 |
| 原话 | 引一句客户的原话作为出处 |

同一件事客户讲了几遍、细节不一样的，不要挑一个版本，把各版本并排记下来，差异点标出来。这正是律师最需要知道的。

遇到性暴力：记下是否发生、大致时间、有没有报案、有没有就医记录，不展开经过细节。口述里有细节也不要搬进案卷，律师需要时自己去看原始记录。

### 2. 排时间线

把事件按时间排序。能排定的排定；只知道相对顺序的（"被抓是在我开始参加聚会之后"）按相对顺序放；完全不知道的放到"位置不明"一栏。

排序时会暴露三类问题，都要标出来：

- **顺序冲突**：A 处说先被警告后被抓，B 处说被抓的时候还没收到警告
- **时间空白**：从第二次被拘到离境之间隔了十四个月，这段客户几乎没讲
- **不合常理的间隔**：说被威胁后"马上就走了"，但又说走的时候是夏天，而威胁在上一年冬天

不要自己推算日期——不要算某天是星期几、两地开车多久、某个公共事件是哪天。只比客户自己前后说的。

### 3. 人物与组织

列出口述里出现的所有人和组织：姓名或称呼、和客户的关系、在案件里起什么作用（迫害者、证人、家属、同伴）、现在在哪、能否联系到、能否出证词。

迫害者单独标：是政府人员（警察、国保、村委）还是私人（亲戚、教会反对者、帮派）。私人迫害的，另记客户有没有报警、警方怎么处理的——这决定"政府不能或不愿保护"这一要件。

### 4. 对照法律要件

庇护案法官要逐项认定的东西，每一项去口述里找支撑。对每项写三栏：**口述里有什么**、**缺什么**、**要追问什么**。

- **过去迫害**：发生了什么、严重到什么程度（拘留、殴打、受伤、就医、财产、工作）。单次威胁和多次拘留的分量不一样。
- **回国的风险**：针对他个人的还是泛泛的？他离开后家人有没有被找？同样情况的人现在怎么样？
- **受保护理由与关联（nexus）**：迫害者为什么针对他——政治观点、宗教、种族、国籍、特定社会团体（PSG）。有别的动机（经济纠纷、私怨、治安）不要紧，受保护的理由要是主要原因之一。口述里常见的问题是客户讲了"被打"但没讲"为什么是我"。PSG 案件另记群体怎么界定。
- **迫害者身份**：政府，还是政府不能或不愿控制的私人。
- **国内迁移**：为什么不能换个城市住？客户有没有试过？迫害者是地方的还是全国性的？
- **一年期限**：入境日期、递交日期；超过一年的，有没有情况变化或特殊情况。
- **第三国与禁止事由**：有没有在第三国长期居留、拿身份；有没有犯罪记录；有没有参与迫害他人；有没有协助过组织。
- **Withholding / CAT**：标准不同（更可能发生 / 更可能被酷刑），如果庇护有一年期限或禁止事由问题，这两项的事实基础单独看。

### 5. 证据地图

每个关键事实应该有什么材料，客户有没有：

| 事实类型 | 应有的材料 |
|---|---|
| 拘留 | 拘留通知书、释放证明、家属证词 |
| 受伤 | 医疗记录、照片、医生证词 |
| 宗教 / 政治活动 | 照片、聊天记录、同伴证词、组织证明 |
| 报警 | 报警回执、警方不受理的记录 |
| 身份与行程 | 护照、签证、机票、出入境记录 |
| 家人情况 | 家人证词、后续被骚扰的记录 |

对每项记：有 / 没有 / 不确定；没有的，客户说为什么拿不到、现在能不能补；有的，原件在哪、谁给的、翻译过没有。

**证据缺口本身也是案情的一部分**：合理能拿到的佐证没拿，法官会问为什么。

### 6. 矛盾与薄弱点

把前面几步里暴露出来的问题汇总，按风险排序。常见的几类：

- **前后不一**：同一件事两种说法（引两句原话并排）
- **生活逻辑**：被拘留审讯后继续住原处、正常上班；之后顺利办护照、从机场用真实身份出境；回过国；被警告后继续同样活动；受伤没就医、没报警；到美国后过了很久才申请
- **讲得出结论讲不出场景**：说"他们天天来骚扰"，但一次具体的也描述不出
- **数字含糊**：报了数又改口；"大概十几天"后来变"一个月"
- **关联性薄弱**：讲了被打，没讲迫害者知道他的身份或观点
- **听说当亲历**：家人转告的事当作自己看见的讲
- **已有书面材料对不上**：如果附了 I-589 草稿或旧陈述，口述和书面的差异逐条列

每条写：问题是什么、涉及哪件事（引原话）、为什么法官会在意、建议怎么问。

**写法上只提问题，不下结论。** 不写"客户说法不实""难以采信"，写"两处说法不一致，需核实哪一处准确"。矛盾可能有合理解释（翻译、记忆、创伤），那是律师和客户要去弄清的，案卷的工作是把它摆出来。

### 7. 待追问清单

把所有"要追问什么"汇总成一份清单，按优先级排：先是影响法律要件成立的，再是影响可信度的，最后是补证据的。每个问题具体到可以直接拿去问客户的程度——不是"核实拘留细节"，而是"第一次被带走是哪个派出所？在里面关了几天几夜？出来时有没有签任何东西？"

## 输出格式

用下面的结构，标题照用，按顺序写。没有内容的部分写"口述未涉及"，不要删掉标题——空着的标题本身就在告诉律师哪里没问到。

```
# 案卷整理：[客户姓名或代号]

整理日期 / 材料来源 / 口述语言 / 口述人

## 一、案情概要
三到五句话。客户是谁，为什么说回国会被迫害，核心事件是什么。只概括，不评价。

## 二、事实清单
按事件编号。每条：事件 · 日期 · 时长/次数 · 地点 · 在场的人 · 客户怎么知道的 · 原话 · 备注（多版本差异在此）

## 三、时间线
排定的 / 相对顺序 / 位置不明。冲突和空白单独标。

## 四、人物与组织

## 五、法律要件对照
逐项：有什么 / 缺什么 / 要追问什么

## 六、证据地图

## 七、矛盾与薄弱点
按风险排序

## 八、待追问清单
按优先级排序，问题写到能直接问的程度

## 九、整理说明
材料里哪些没法判断、哪些做了假定、哪些需要律师自己看原始记录
```

案卷的语言跟口述走：客户说中文就用中文整理，法律术语保留英文原词（I-589、PSG、nexus、CAT、withholding）方便律师对照表格。律师要求英文版的，法律要件和待追问清单先给英文。

## 几条不能让步的

- **不补事实。** 没说的就是没说。不替客户猜日期，不推算间隔，不根据常识补一个"应该是"的细节。
- **不改数字。** 客户说十天就是十天，说"好几天"就是"好几天"。
- **不选版本。** 两种说法都保留，差异标出来。
- **不下结论。** 案卷里没有"可信""不可信""符合""不符合"，只有"有支撑""缺支撑""需核实"。
- **不扩性暴力细节。** 确认发生与否、时间、报案就医情况，到此为止。
- **未成年时期的事**，日期和数字问参照物（几年级、什么季节），缺精确数字不算薄弱点。
- **材料不外传。** 案卷涉及客户身份和迫害细节，整理在本地完成，不发到外部服务。

## 示例片段

口述原文（节选）：

> 我是 2019 年开始去家庭教会的，就是我们村一个姐妹家里。去了大概半年多吧，有一天晚上警察就来了，把我们都带走了。关了……我记得是三天还是五天，反正放出来之后他们让我签了个保证书。后来我就不敢去了。然后到了 2020 年，我又去了几次，又被抓了一次，这次关了半个月。

拆出的事实：

```
事件 2 · 第一次被带走
日期：2019 年开始去教会后"大概半年多"（相对日期，锚点：开始参加家庭教会，2019 年，月份未提及）
时长：客户先说"三天还是五天"，未确定
地点：带走地点为姐妹家中；关押地点未提及
在场的人：警察（人数未提及）、聚会的其他人（人数未提及）
客户怎么知道的：亲身经历
原话："关了……我记得是三天还是五天"
备注：签了"保证书"，内容未提及，有无副本未提及

事件 3 · 第一次被带走后
"后来我就不敢去了" 与 "到了 2020 年，我又去了几次" 并存
→ 列入薄弱点：被警告后继续同样活动，需问客户为什么又去、中间隔了多久、2020 年去的几次是否被人知道
```

待追问（节选）：

```
1. [要件·过去迫害] 第一次被关是三天还是五天？在里面有没有被打、被审问？谁审的？
2. [要件·迫害者] 带走您的是哪个单位？派出所、国保还是别的？有没有看到证件或车辆标识？
3. [证据] 保证书签了之后给您副本了吗？内容大概是什么？
4. [薄弱点] 签了保证书之后"不敢去了"，后来为什么又去？隔了多久？是同一个聚会点吗？
5. [要件·关联] 警察带走您的时候说了为什么吗？是针对聚会，还是针对您个人？
```
